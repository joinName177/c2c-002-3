# c2c-002 · 情绪植物园

Vue 3 + TypeScript + Vite 纯前端情绪记录与虚拟植物花园。每日记录情绪会种下一株对应植物，连续记录让植物从种子、发芽、开花到结果；断签后保留枯萎标本，并提供生长时间轴和情绪生态年报。数据保存在浏览器 `localStorage`。

## 分层

- 核心层 `src/core`：情绪记录、连续天数、植物生长阶段、枯萎判断、生态年报、备份导出/导入与校验（`backup.ts`）
- 端口层 `src/ports`：花园快照仓储接口
- 适配器层 `src/adapters`：浏览器本地存储实现
- 界面层 `src/ui`：Vue 页面与原生 CSS 视图

## 备份导出 / 导入

顶栏「导出备份」把全部情绪记录和植物状态导出为带 `app` 标识与版本号的 JSON 文件（`emotion-garden-backup-YYYYMMDD-HHMM.json`）；「导入恢复」先在内存中完成校验与预览，确认后才写入：

- 校验：JSON 结构、来源标识、版本号（旧版本无版本号的裸快照走兼容读取并标注；更新版本直接拒绝），逐条核对日期（真实日历日期）、情绪枚举、字段类型；结构损坏或一条可用记录都没有时**不会触碰现有数据**。
- 能救多少救多少：字段缺失/越界可自动修正（id 缺失或重复重新生成、空备注补默认寄语、强度夹到 1–5）并计数；无法识别的条目进入跳过清单，明确提示恢复了几条、跳过了几条及原因。
- 三种合并策略：合并保留现有（默认）、合并以文件为准、整体覆盖。冲突按「同一天 + 同一情绪」判定，`dedupeEntries` 保证任何来源都不会重复累计连续天数与年报。
- 恢复后统一重算：植物连续天数、生长阶段、枯萎状态、entryIds 全部按合并后的记录重建；年报为派生数据随之刷新。
